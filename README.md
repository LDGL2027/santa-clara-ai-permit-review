# AI for Building Permit Review

**Client:** County of Santa Clara, Department of Planning and Development

**Team:** Group 5, August–October 2026

**My part:** Helped conduct TRACE red-teaming and identified a jurisdiction validation failure involving an Oakland permit application. Documented the issue and proposed improvements in our team's TRACE report.

## The Problem
Santa Clara County staff must review building permit applications, identify missing information, and ensure applications meet county requirements. Manual review can be time-consuming and may delay processing.

## What We Built
- An AI-assisted building permit review prototype that helps staff screen applications.
- An applicant portal and a staff portal for reviewing permit information.
- A system that flags missing information and potential issues while keeping final approval decisions with human staff.

## What I Would Do Next
I would improve address verification and test the system using more realistic applications to make sure it handles different situations correctly.
